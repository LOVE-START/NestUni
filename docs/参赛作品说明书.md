## 一、作品简介

随着高校社团管理数字化转型的加速推进，传统的社团管理方式已难以满足现代大学生对社团信息获取、活动参与、招新报名等方面的便捷化需求。社团信息分散、活动通知不及时、招新流程繁琐、用户参与度难以量化等问题日益凸显，亟需一个集社团展示、活动管理、智能服务于一体的综合性平台来解决这些痛点。

针对上述问题，本作品设计并实现了"羽巢Nest·高校智慧社团生态平台"，这是一个基于微信小程序的智慧社团管理系统。该平台整合了社团展示、活动管理、招新报名、AI智能助手、羽章激励系统等核心功能模块，采用前后端分离架构，前端基于微信小程序原生框架开发，后端采用Node.js + Express构建RESTful API，数据库使用MySQL存储业务数据。

本作品的核心创新点包括：

1. **AI智能助手"小苑"**：基于阿里云通义千问(Qwen)大语言模型，实现了意图识别、上下文增强、个性化推荐等功能，能够智能回答用户关于社团推荐、活动查询、招新咨询等问题，并提供精准的推荐卡片展示。

2. **羽章激励系统**：设计了成就型、等级型、身份型三种羽章类型，结合四级稀有度系统（普通/稀有/史诗/传说），通过自动触发机制激励用户活跃，记录用户成长历程，增强社交展示属性。

3. **智能通知系统**：基于微信订阅消息，实现了面试通知、活动提醒、新活动推送、审核结果通知等多场景通知功能，确保信息及时触达用户。

4. **数据分析看板**：为社团管理者提供运营数据可视化，包括成员统计、活动分析、招新转化等核心指标，支持趋势分析和时间周期切换。

### 1、AI智能助手模块

本作品的AI智能助手"小苑"是基于大语言模型的智能对话系统，能够理解用户意图并提供个性化的社团推荐、活动查询、招新咨询等服务。该模块的核心技术包括意图识别、上下文增强和推荐卡片生成。

#### 1.1 意图识别算法

意图识别是AI助手理解用户需求的关键步骤。本作品设计了一套基于关键词匹配和语义理解的意图识别算法，能够准确识别用户的查询意图。

**意图类型定义：**

| 意图类型 | 关键词示例 | 功能描述 |
|---------|-----------|---------|
| club_recommend | 推荐、社团、加入 | 社团推荐 |
| event_recommend | 活动、近期、热门 | 活动推荐 |
| nearby_event | 附近、周边、最近 | 附近活动 |
| recruitment_info | 招新、报名、加入 | 招新信息 |
| club_info | 社团介绍、详情 | 社团详情 |
| badge_info | 羽章、徽章、成就 | 羽章查询 |
| badge_recommend | 推荐羽章、获得 | 羽章推荐 |
| general_chat | 其他 | 通用对话 |

**意图识别流程：**

```
用户消息 → 关键词提取 → 意图匹配 → 返回意图类型
                ↓
         未匹配到 → 返回 general_chat
```

意图识别算法的核心实现如下：

```javascript
/**
 * 意图识别函数

function detectIntent(message) {

  // 社团推荐意图

  }
  
  // 活动推荐意图
  if (INTENT_KEYWORDS.event_recommend.some(kw => lowerMessage.includes(kw))) {
    return 'event_recommend';
  }
  
  // ... 其他意图判断
  
  return 'general_chat';
}
```

### 2、羽章激励系统

羽章激励系统是本作品的核心创新之一，通过勋章激励机制提升用户活跃度、记录用户成长历程、增强社交展示属性。

#### 2.1 活跃度计算模型

用户活跃度是羽章激励系统的核心指标，本作品设计了一套基于加权求和的活跃度计算模型。

**活跃度计算公式：**

$$S = \min(100, \lfloor w_1 \cdot L + w_2 \cdot E + w_3 \cdot C + w_4 \cdot A \rfloor)$$

其中：
- $S$ 表示活跃度分数，取值范围为 [0, 100]
- $L$ 表示近30天的页面访问次数
- $E$ 表示近30天的活动参与次数
- $C$ 表示近30天的评论发表次数
- $A$ 表示近30天的招新报名次数
- $w_1, w_2, w_3, w_4$ 为权重系数，分别取值为 1, 5, 2, 3

**权重设计原理：**

| 行为类型 | 权重 | 设计理由 |
|---------|------|---------|
| 页面访问 | 1 | 基础行为，鼓励用户经常使用平台 |
| 活动参与 | 5 | 核心行为，社团活动的参与度最重要 |
| 评论互动 | 2 | 社交行为，促进用户间的互动交流 |
| 招新报名 | 3 | 成长行为，鼓励用户加入社团 |

**活跃度等级划分：**

根据活跃度分数，将用户划分为四个等级：

$$
\text{等级} = 
\begin{cases}
\text{青铜} & 1 \leq S \leq 30 \\
\text{白银} & 31 \leq S \leq 60 \\
\text{黄金} & 61 \leq S \leq 80 \\
\text{钻石} & 81 \leq S \leq 100
\end{cases}
$$

**算法实现：**

```javascript
/**
 * 计算用户活跃度分数
 * @description 基于最近30天的统计数据计算活跃度分数
 * 计算规则：页面访问×1 + 参与活动×5 + 评论×2 + 报名×3，最高100分
 */
async function calculateActivityScore(userId) {
  const thirtyDaysAgo = new Date();
  thirtyDaysAgo.setDate(thirtyDaysAgo.getDate() - 30);

  const stats = await knex('user_activity_stats')
    .where('user_id', userId)
    .where('stat_date', '>=', thirtyDaysAgo)
    .select(
      knex.raw('SUM(login_count) as total_logins'),
      knex.raw('SUM(event_count) as total_events'),
      knex.raw('SUM(comment_count) as total_comments'),
      knex.raw('SUM(application_count) as total_applications')
    )
    .first();

  const score = Math.min(100, Math.floor(
    (stats.total_logins || 0) * 1 +
    (stats.total_events || 0) * 5 +
    (stats.total_comments || 0) * 2 +
    (stats.total_applications || 0) * 3
  ));

  return score;
}
```

#### 2.4 羽章推荐算法

为了智能推荐适合用户的羽章，本作品设计了基于匹配度的推荐算法。

**匹配度计算公式：**

对于等级型羽章，匹配度计算公式为：

$$M = \max(0, 100 - (S_{target} - S_{current}) \times 2)$$

其中：
- $M$ 表示匹配度分数，取值范围为 [0, 100]
- $S_{target}$ 表示羽章要求的活跃度分数
- $S_{current}$ 表示用户当前的活跃度分数

**进度百分比计算公式：**

$$P = \min(100, \frac{C}{T} \times 100\%)$$

其中：
- $P$ 表示进度百分比
- $C$ 表示当前完成值
- $T$ 表示目标值

**综合匹配度计算：**

对于成就型羽章，综合考虑进度和兴趣匹配度：

$$M_{total} = M_{progress} + M_{interest}$$

其中：
- $M_{progress}$ 表示进度匹配度（基础分）
- $M_{interest}$ 表示兴趣匹配度（加分项，取值 0-20）

**算法实现：**

```javascript
/**
 * 生成羽章推荐
 * @description 根据用户画像、活跃度、兴趣关键词智能推荐羽章
 */
async function generateBadgeRecommendations(userId, unearnedBadges, userProfile, activityScore, message) {
  const recommendations = [];
  
  for (const badge of unearnedBadges) {
    const recommendation = {
      badge: badge,
      matchScore: 0,
      reasons: [],
      progress: null
    };
    
    // 等级型羽章匹配度计算
    if (badge.type === 'level' && condition.conditions) {
      const { min, max } = condition.conditions.activity_score || {};
      if (min !== undefined && max !== undefined) {
        if (activityScore >= min && activityScore <= max) {
          recommendation.matchScore = 100;
          recommendation.reasons.push(`你的活跃度${activityScore}分，正好符合此羽章要求`);
        } else if (activityScore < min) {
          recommendation.matchScore = Math.max(0, 100 - (min - activityScore) * 2);
          recommendation.reasons.push(`再提升${min - activityScore}分活跃度即可获得`);
          recommendation.progress = {
            current: activityScore,
            target: min,
            percentage: Math.round((activityScore / min) * 100)
          };
        }
      }
    }
    
    // 成就型羽章进度计算
    if (badge.type === 'achievement') {
      const progress = await calculateAchievementProgress(userId, condition.conditions);
      recommendation.progress = progress;
      
      if (progress.percentage >= 80) {
        recommendation.matchScore = 90;
        recommendation.reasons.push(`即将完成！进度${progress.percentage}%`);
      } else if (progress.percentage >= 50) {
        recommendation.matchScore = 70;
        recommendation.reasons.push(`进度良好，已完成${progress.percentage}%`);
      } else {
        recommendation.matchScore = 40;
      }
    }
    
    // 兴趣匹配加分
    if (interestInfo.categories.includes(badge.category.toLowerCase())) {
      recommendation.matchScore += 20;
      recommendation.reasons.push(`符合你提到的兴趣：${interestInfo.keywords.join('、')}`);
    }
    
    if (recommendation.matchScore > 0) {
      recommendations.push(recommendation);
    }
  }
  
  // 按匹配度降序排序
  recommendations.sort((a, b) => b.matchScore - a.matchScore);
  
  return recommendations.slice(0, 10);
}
```

#### 2.5 自动触发机制

羽章系统通过监听用户行为事件，自动判断是否满足羽章获取条件。

**触发流程：**


#### 3.2 Access Token缓存机制

为了提高通知发送效率，本作品实现了Access Token缓存机制：

```javascript
/**
 * Access Token缓存
 */
let accessTokenCache = {
  token: null,
  expiresAt: 0
};

/**
 * 获取微信Access Token
 * @description 带缓存机制，避免频繁请求
 */
async function getAccessToken() {
  const now = Date.now();
  
  // 缓存有效，直接返回
  if (accessTokenCache.token && accessTokenCache.expiresAt > now) {
    return accessTokenCache.token;
  }
  
  // 请求新Token并缓存
  const response = await axios.get('https://api.weixin.qq.com/cgi-bin/token', {
    params: {
      grant_type: 'client_credential',
      appid: WECHAT_CONFIG.appId,
      secret: WECHAT_CONFIG.secret
    }
  });
  
  accessTokenCache.token = response.data.access_token;
  accessTokenCache.expiresAt = now + (response.data.expires_in - 300) * 1000;
  
  return accessTokenCache.token;
}
```

#### 4.1 趋势分析算法

为了帮助管理者了解数据变化趋势，本作品设计了趋势百分比计算算法。

**趋势百分比计算公式：**

$$T = \frac{C - P}{P} \times 100\%$$

其中：
- $T$ 表示趋势百分比
- $C$ 表示当前周期的数值
- $P$ 表示上一周期的数值

**特殊情况处理：**

当 $P = 0$ 时：
$$
T = 
\begin{cases}
100\% & C > 0 \\
0\% & C = 0
\end{cases}
$$

**算法实现：**

```javascript
/**
 * 计算趋势百分比
 * @description 计算当前值相对于之前值的变化百分比
 */
function calculateTrend(current, previous) {
  if (previous === 0) return current > 0 ? 100 : 0;
  return Math.round(((current - previous) / previous) * 100);
}
```

#### 4.2 地理距离计算

为了实现附近活动推荐功能，本作品采用Haversine公式计算两点间的球面距离。

**Haversine公式：**

$$d = 2R \cdot \arcsin\left(\sqrt{\sin^2\left(\frac{\varphi_2 - \varphi_1}{2}\right) + \cos(\varphi_1)\cos(\varphi_2)\sin^2\left(\frac{\lambda_2 - \lambda_1}{2}\right)}\right)$$

其中：
- $d$ 表示两点间的球面距离（米）
- $R$ 表示地球半径，取值 6,371,000 米
- $\varphi_1, \varphi_2$ 分别表示起点和终点的纬度（弧度）
- $\lambda_1, \lambda_2$ 分别表示起点和终点的经度（弧度）

**角度转弧度公式：**

$$\theta_{rad} = \theta_{deg} \times \frac{\pi}{180}$$

**算法实现：**

```javascript
/**
 * 计算两点之间的距离（Haversine公式）
 * @param {number} lat1 - 起点纬度
 * @param {number} lon1 - 起点经度
 * @param {number} lat2 - 终点纬度
 * @param {number} lon2 - 终点经度
 * @returns {number} 距离（米）
 */
function calculateDistance(lat1, lon1, lat2, lon2) {
  const R = 6371000;  // 地球半径（米）
  const dLat = (lat2 - lat1) * Math.PI / 180;
  const dLon = (lon2 - lon1) * Math.PI / 180;
  const a = Math.sin(dLat / 2) * Math.sin(dLat / 2) +
            Math.cos(lat1 * Math.PI / 180) * Math.cos(lat2 * Math.PI / 180) *
            Math.sin(dLon / 2) * Math.sin(dLon / 2);
  const c = 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1 - a));
  return R * c;
}
```

**应用场景：**

该算法用于"附近活动"功能，根据用户当前位置计算与各活动地点的距离，并按距离排序推荐最近的活动。

#### 5.2 转化漏斗分析

为了帮助社团管理者了解招新效果，本作品设计了转化漏斗分析模型。

**转化率计算公式：**

$$R_i = \frac{N_i}{N_{i-1}} \times 100\%$$

其中：
- $R_i$ 表示第 $i$ 阶段的转化率
- $N_i$ 表示第 $i$ 阶段的人数
- $N_{i-1}$ 表示第 $i-1$ 阶段的人数

**整体转化率计算：**

$$R_{total} = \frac{N_{final}}{N_{initial}} \times 100\%$$

其中：
- $R_{total}$ 表示整体转化率
- $N_{final}$ 表示最终录取人数
- $N_{initial}$ 表示初始报名人数

**漏斗阶段定义：**

| 阶段 | 说明 | 计算方式 |
|------|------|---------|
| 报名提交 | 用户提交报名申请 | $N_1$ = 报名总数 |
| 已查看 | 社团查看报名信息 | $R_2 = N_2 / N_1$ |
| 面试中 | 进入面试环节 | $R_3 = N_3 / N_2$ |
| 已录取 | 最终录取 | $R_4 = N_4 / N_3$ |

```javascript
/**
 * 生成JWT Token
 */
function generateToken(userId, role) {
  return jwt.sign(
    { userId, role },
    process.env.JWT_SECRET,
    { expiresIn: '7d' }
  );
}

/**
 * 验证Token中间件
 */
function authMiddleware(req, res, next) {
  const token = req.headers.authorization?.split(' ')[1];
  
  if (!token) {
    return res.status(401).json({ error: '未授权访问' });
  }
  
  try {
    const decoded = jwt.verify(token, process.env.JWT_SECRET);
    req.user = decoded;
    next();
  } catch (error) {
    return res.status(401).json({ error: 'Token无效或已过期' });
  }
}
```
