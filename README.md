# 羽巢Nest·高校智慧社团生态平台

## 项目概述

羽巢Nest是一个面向全国高校的智慧社团生态平台，基于微信小程序开发，提供社团展示、活动管理、招新报名、AI智能助手、羽章激励系统等核心能力。

## 核心功能模块

### 1. 社团管理模块

- **社团浏览**: 按分类筛选（学术、艺术、体育、文化、公益等）、关键词搜索
- **社团详情**: 展示社团介绍、相册、公告、活动、招新信息
- **社团管理**: 社团会长可编辑社团信息、管理成员、发布公告
- **成员管理**: 添加/移除成员、设置成员角色、查看成员列表

### 2. 活动管理模块

- **活动浏览**: 按分类和日期筛选、搜索功能
- **活动报名**: 在线报名、取消报名、查看参与者
- **活动管理**: 创建/编辑活动、设置报名要求、管理参与者
- **活动地图**: 在地图上展示活动位置、支持导航功能
- **状态管理**: 活动发布、取消、完成等状态流转

### 3. 招新系统模块

- **招新发布**: 发布招新信息、设置报名要求和截止时间
- **自定义表单**: 支持自定义报名表单字段，收集申请人信息
- **报名管理**: 查看所有报名申请、进行状态流转
- **面试安排**: 设置面试时间、地点、联系方式，通知申请人
- **状态流转**: 已提交 → 已查看 → 面试中 → 已录取/已拒绝
- **我的报名**: 查看所有报名记录和状态

### 4. AI智能助手模块

- **智能对话**: 基于通义千问(Qwen)的AI助手"小苑"，提供社团推荐、活动查询、招新咨询等服务
- **上下文理解**: AI助手根据用户画像和历史行为提供个性化推荐
- **意图识别**: 自动识别用户意图（社团推荐、活动推荐、招新信息等）
- **推荐卡片**: 在对话中展示社团、活动、羽章等推荐卡片
- **智能问答**: 支持羽章查询、活跃度查询、帮助指南等
- **Agent 工具调用（V1.9）**: 助手由问答式 Pipeline 升级为工具调用型智能体，可在对话中完成活动报名/取消、活动审核、会长补录成员，并实时查询活动、社团、个人概览与待审核列表（共 8 个业务工具）
- **二次确认与安全防护**: 写操作须经确认卡片点击后执行，采用工具白名单、JWT 身份绑定、双重权限校验、HMAC 确认令牌、频控与全量审计五层防护；首轮模型调用失败时自动降级回 Pipeline 模式
- **管理员 AI 助手**: 管理员端可在对话中查询待审核列表并完成通过/拒绝审核
- **工具步骤条**: 展示 Agent 本次执行了哪些动作，关键操作可见、可确认、可追溯

### 5. 羽章激励系统

- **成就型羽章**: 记录用户关键里程碑（首次登录、加入社团、参与活动等）
- **等级型羽章**: 根据用户活跃度动态变化的等级徽章（青铜/白银/黄金/钻石）
- **身份型羽章**: 标识用户特殊身份（社团会长、管理员、认证用户等）
- **稀有度系统**: 四级稀有度（普通/稀有/史诗/传说），配合视觉效果
- **自动触发**: 监听用户行为事件，自动判断并发放羽章
- **社交展示**: 在个人中心、评论区等位置展示羽章

### 6. 智能通知系统

- **面试通知**: 通知申请人参加面试（时间、地点、联系方式）
- **活动开始提醒**: 提醒用户活动即将开始
- **新活动通知**: 向社团成员推送新活动信息
- **审核结果通知**: 通知会长审核结果（通过/拒绝）
- **待审核提醒**: 提醒老师有新的活动/公告待审核
- **批量发送**: 支持批量发送通知给多个用户

### 7. 审核系统模块

- **内容审核**: 活动和公告需经管理员/老师审核后发布
- **审核流程**: 提交审核 → 待审核 → 审核通过/拒绝
- **审核记录**: 记录审核历史、审核人、拒绝原因等
- **权限分级**: 超级管理员、普通管理员、教师三种审核权限

### 8. 公告系统模块

- **社团公告**: 社团会长发布社团公告
- **系统公告**: 管理员发布全局系统公告
- **公告管理**: 编辑、删除公告
- **公告弹窗**: 首次打开小程序时展示系统公告

### 9. 用户系统模块

- **微信登录**: 支持微信一键登录
- **个人信息管理**: 完善个人资料（头像、学号、微信号等）
- **个人中心**: 展示参与的社团、活动、羽章、报名记录
- **权限管理**: 三级权限体系（普通用户、社团会长、系统管理员）
- **活跃度统计**: 记录用户登录、活动参与、评论等行为数据

### 10. 互动交流模块

- **评论系统**: 在活动页面发表评论
- **成员互动**: 查看社团成员列表

### 11. 地图导航模块

- **活动地图**: 在地图上展示各活动的位置信息
- **路线导航**: 支持从用户当前位置到活动地点的路线规划与导航
- **位置标记**: 点击地图标记可查看活动详情
- **距离显示**: 实时显示用户与活动地点的距离

### 12. 数据分析模块

- **社团概览**: 展示社团核心运营指标（成员数、活动数、招新数、活跃度）
- **趋势分析**: 支持本学期/本学年时间周期切换，展示数据变化趋势
- **活动统计**: 活动参与趋势图、活动类型分布、参与率排行
- **成员统计**: 成员活跃度趋势、等级分布（青铜/白银/黄金/钻石）、活跃排行榜
- **招新统计**: 转化漏斗分析、历年招新对比、招新来源分布
- **管理员概览**: 全校社团数据汇总、社团活跃度排名、活动分类统计
- **可视化图表**: 使用 ECharts 实现折线图、饼图等数据可视化

### 13. 微信消息推送模块

- **服务器验证**: 支持微信服务器地址验证
- **消息接收**: 接收微信服务器推送的消息和事件
- **事件处理**: 处理用户关注/取消关注等事件
- **文本消息**: 支持接收和回复用户文本消息
- **安全模式**: 支持消息加解密，确保通信安全

### 14. 报名操作日志模块

- **操作记录**: 记录报名状态变更的完整历史
- **操作追溯**: 支持查看报名的操作时间线
- **状态追踪**: 自动记录状态变更（提交/查看/面试/录取/拒绝）
- **操作人信息**: 记录操作人ID、姓名、角色等信息

## 技术特点

### 前端技术

- **微信小程序原生框架**: 采用原生开发，性能更优
- **组件化开发**: 16个自定义组件，提高代码复用性
- **主题系统**: 支持动态渐变换色，提供个性化体验
- **图片缓存机制**: 预加载和缓存图片，提升用户体验
- **响应式布局**: 适配不同屏幕尺寸
- **懒加载优化**: 按需加载组件，减少首屏加载时间

### 后端技术

- **Node.js + Express**: 构建RESTful API
- **MySQL + Knex.js**: 数据库存储和查询构建
- **JWT Token认证**: 安全的用户认证机制
- **权限控制系统**: 三级权限管理
- **Winston日志记录**: 完善的日志系统
- **请求速率限制**: 防止恶意攻击
- **事务处理**: 确保数据一致性

### AI服务

- **通义千问(Qwen)**: 阿里云DashScope API，默认模型 `qwen-flash`（稳定别名，自动跟随最新版本），主模型不可用时按 `qwen-plus` → `qwen-max` 自动降级；可通过 `.env` 的 `QWEN_MODEL`、`QWEN_FALLBACK_MODELS` 调整
- **上下文增强**: 根据用户意图检索数据库，构建上下文
- **意图识别**: 自动识别用户意图，提供精准回答
- **推荐系统**: 基于用户画像的个性化推荐
- **Agent 引擎（V1.9）**: DashScope Function Calling（tools 参数）驱动"决策—执行—回填"工具循环，模型只决策、后端只执行；旧 Pipeline 保留为降级通道（`AGENT_ENABLED=false` 或首轮失败自动回退）
- **五层安全机制**: 工具白名单（8 个纯业务工具）、参数 Schema 清洗、身份绑定与执行层双校验、写操作二次确认（HMAC 令牌 5 分钟有效、单次消费）、频控与审计日志
- **会话身份化**: `chat_sessions.owner_type` 隔离学生与管理员会话；业务逻辑下沉至 Service 层供路由与 Agent 共用

### 通知服务

- **微信订阅消息**: 微信小程序订阅消息推送
- **多场景通知**: 面试、活动、审核等多种通知场景
- **批量发送**: 支持批量发送通知
- **模板管理**: 集中管理通知模板ID

## API 接口

### 认证相关 `/nfunest/api/auth`

- 用户登录、管理员登录
- Token验证、用户信息获取

### 社团相关 `/nfunest/api/clubs`

- 社团列表、详情、创建、编辑、删除
- 成员管理、公告管理

### 活动相关 `/nfunest/api/events`

- 活动列表、详情、创建、编辑、删除
- 报名管理、参与者管理
- 地图数据获取

### 招新相关 `/nfunest/api/recruitments`

- 招新列表、详情、创建、编辑、删除
- 报名提交、状态更新
- 我的报名、社团报名管理

### AI聊天相关 `/nfunest/api/chat`

- 创建会话、获取历史消息
- 发送消息、获取AI回复；响应含 `agent.steps`（工具步骤）与 `agent.pendingAction`（待确认操作：token / tool / summary）
- `POST /sessions/:id/confirm`: 确认执行写操作（actionToken + messageId）
- `POST /sessions/:id/cancel-action`: 取消待确认操作并回写审计终态
- 全部聊天接口经 Agent 专用限流（每 IP 每分钟 20 次）

### 羽章相关 `/nfunest/api/badges`

- 羽章列表、详情
- 我的羽章、羽章统计
- 更新展示设置

### 通知相关 `/nfunest/api/notifications`

- 获取模板ID列表
- 发送面试通知、活动提醒、新活动通知
- 通用模板消息发送 `/send`（审核结果、待审核提醒等场景由业务层内部自动触发，不单独暴露接口）

### 审核相关 `/nfunest/api/approvals`

- 提交审核、审核通过/拒绝
- 获取待审核列表、审核历史

### 公告相关 `/nfunest/api/announcements`

- 公告列表、创建、编辑、删除

### 评论相关 `/nfunest/api/comments`

- 评论列表、创建、删除

### 上传相关 `/nfunest/api/upload`

- 图片上传、多文件上传
- 文件删除

### 系统相关 `/nfunest/api`

- 健康检查
- 数据同步
- 系统配置

### 数据统计相关 `/nfunest/api`

- 社团概览数据
- 活动数据统计
- 成员数据统计

## 使用说明

### 前端部署

1. 确保已安装微信开发者工具
2. 导入项目到微信开发者工具
3. 配置 [app.js](file:///D:/Learn/WechatProject/NFUNest/app.js) 中的 apiBaseUrl 为你的后端服务地址
4. 编译并预览项目

### 后端部署

1. 安装 Node.js 环境
2. 进入 backend 目录，执行 `npm install`
3. 配置环境变量（创建 .env 文件）：
   ```
   DB_HOST=your_database_host
   DB_USER=your_database_user
   DB_PASSWORD=your_database_password
   DB_NAME=nfunest
   WECHAT_APPID=your_wechat_appid
   WECHAT_SECRET=your_wechat_secret
   QWEN_API_KEY=your_qwen_api_key
   ```
4. 导入数据库结构：`mysql -u root -p nfunest < nfunest.sql`
5. 启动服务：`npm start` 或 `npm run dev`（开发模式）

## 设计理念

我们参考了现代化的移动端设计规范，注重以下几点：

1. **简洁直观**: 去除冗余元素，突出核心信息
2. **一致性强**: 统一的视觉风格和交互模式
3. **响应迅速**: 优化加载性能和交互反馈
4. **易于维护**: 采用组件化开发，便于后续扩展
5. **智能化**: AI助手提供个性化服务
6. **激励性**: 羽章系统提升用户活跃度

## 功能亮点

1. **AI智能助手**: 基于通义千问的智能对话与 Agent 工具调用，提供社团推荐、活动查询、报名/审核代办与安全二次确认（设计文档见 `docs/superpowers/plans/2026-08-23-agent-upgrade.md`）
2. **羽章激励系统**: 成就型、等级型、身份型羽章，激励用户活跃
3. **智能通知系统**: 多场景订阅消息推送，确保信息及时触达
4. **三级权限管理**: 普通用户、社团会长、系统管理员各有不同权限
5. **数据缓存机制**: 采用本地缓存减少网络请求，提升响应速度
6. **主题系统**: 支持动态渐变换色，提供个性化体验
7. **地图集成**: 结合微信地图组件，提供地理位置服务
8. **招新报名系统**: 完整的招新流程，从发布到录取全流程管理
9. **审核机制**: 活动/公告多级审核，确保内容质量
10. **活跃度统计**: 记录用户行为数据，计算活跃度得分
11. **数据分析看板**: 社团运营数据可视化，支持趋势分析和对比
12. **微信消息推送**: 支持微信服务器消息推送，实现事件和消息处理
13. **操作日志追溯**: 报名状态变更全程记录，操作可追溯
14. **Agent 五层安全防护**: 工具白名单、身份绑定、双重权限校验、写操作二次确认、频控与审计，让 AI 能办事且不越权
15. **Service 层复用**: 报名/成员管理等业务下沉，页面接口与 Agent 共用同一校验链与通知联动
